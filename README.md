# 身体 · 生理需求

给 AstrBot 的 Persona 一副按真实时间运转的身体：胃内容、血糖、水合、膀胱、皮肤、口腔、睡眠债、女性周期、男性生理。它不是一个会主动说话的角色插件，而是给 Persona 提供“身体背景 + 记录工具”。

这是 astrbot_plugin_persona_presence 的伴侣插件，但它不依赖后者。完整算法、公式和已知简化见 [docs/SIMULATION.md](docs/SIMULATION.md)。

## v2 做了什么

和最初版本相比，v2 不再是七条固定速率的线性坡道：

- 胃内容、血糖、水合、膀胱、皮肤、口腔、睡眠债是独立内部状态。
- 饥饿由“胃空 + 血糖低 + 饭点”推导；口渴由水合推导；膀胱由尿量推导；精力由睡眠债 + 昼夜警觉度 + 饿渴惩罚推导。
- 时间按 15 分钟（前 24 小时）或 1 小时（更久）分段积分，胃排空、血糖消耗、水合下降、膀胱充盈都是连续过程。
- 有昼夜节律：凌晨警觉度低，上午和傍晚高；饭点食欲偏置更高。
- 女性周期有简化的雌激素/孕激素/LH 曲线，症状由周期和稳定随机种子共同决定。
- 男性有欲望、梦遗、晨勃、白天反应和 2-6 小时恢复期；欲望和梦遗概率随年龄变化（青春期到二十出头最高，之后递减）。
- 插件页新增“设置”页签，所有关键配置可改可存，包括成人模块开关。



## 默认跟踪哪个人格

默认只跟踪“当前会话最终生效的人格”：一次 LLM 请求只推进这个人的状态，不会把人格库里所有人都结算一遍。

插件页没有会话上下文，所以默认显示 AstrBot 的默认人格（例如璃月），不会遍历所有人格。

设置页里有一个“固定人格”：

- 留空 = 跟随当前会话的人格。群 A 用璃月，就推进璃月；私聊切到星野泠，就推进星野泠。
- 选一个 = 所有会话都固定使用这个人的身体，聊天里切人格也不会换。

每个人格仍然有自己的 JSON 状态；只有被实际使用或被固定的人格才会被推进，其他旧文件不会被自动遍历。

## 它怎么运转

消息进入 -> 解析 Persona -> 读取该 Persona 的 JSON -> 按经过时间积分 -> 重算显示指标 -> 写回 JSON -> 生成提示块 -> 附加到本次 LLM 请求。

它不会发送消息，不写聊天历史，不替换 Persona 的系统提示。它只在下次开口时把身体状态作为背景交出去；模型可以选择提，也可以忽略。

## 内部状态和显示指标

| 内部状态 | 范围 | 驱动什么 |
| --- | --- | --- |
| 胃内容 | 0-100，越高越饱 | 饥饿 |
| 血糖 | 0-100，越低越饿 | 饥饿、精力 |
| 水合 | 0-100，越低越渴 | 口渴、尿量 |
| 尿量 | 0-100 | 膀胱 |
| 皮肤脏度 | 0-100 | 清洁 |
| 口腔脏度 | 0-100 | 口腔 |
| 睡眠债 | 0-24 小时 | 精力 |
| 欲望 | 0-100 | 亲密张力，ENABLE_INTIMATE 关闭时恒 0 |

显示指标：

    hunger = 0.55 * (100 - 胃内容) + 0.45 * (100 - 血糖) + 饭点偏置
    thirst = 100 - 水合
    bladder = 尿量
    cleanliness = 皮肤脏度
    fatigue = 0.55 * 睡眠债百分比 + 0.45 * (100 - 昼夜警觉度) + 饿渴惩罚

所以“刚吃完但血糖还低”会饿，“睡够但凌晨三点”会困，“喝了很多水”会很快想上厕所。

## 女性周期

周期是锚点 + 日历 + 简化激素曲线 + 稳定随机症状。

- 经期：第 1 到 period_length 天。
- 排卵期：周期中点 ±1 天。
- 黄体期：排卵之后到下次经期前。
- 经期后：其余。

激素：

- 雌激素：经期低，卵泡期上升，排卵期峰值约 90，黄体期下降。
- 孕激素：前半周期低，排卵后上升，黄体中后期峰值约 70，经前下降。
- LH：排卵期峰值 100，其他时间低。

症状包括经量、小腹坠胀、情绪、胃口；同一个周期内稳定，不会每轮刷新都变。经期开始/结束、进入排卵期、进入黄体期都会写事件并去重。

页面会显示三条激素小条；提示词只说身体感受，不直接说激素数值。

## 青春期

年龄 < 18 的角色按青春期处理（年龄从人格正文读，读不到用配置 AGE，都没有就当成年不做青春期）：

- 还没初潮：年龄 < 13 时阶段显示“未初潮”，不出血量、不写经期事件。
- 周期不规律：每个周期在配置长度上下浮动约 ±5 天，所以“距下次”会跳。
- 痛经更常见：经期小腹等级有 35% 概率再 +1。
- 经前反应更强：黄体期情绪额外偏低，经前提示改成“情绪起伏比平时大”。
- 皮脂更多：皮肤脏度涨得更快。
- 提示词会在周期那行后面注明“青春期，周期还不太规律”。

## 男性

只在 ENABLE_INTIMATE 开启、性别 male 时运行；提示词和工具只在私聊出现。

- 欲望：20 岁以下 +2.0/天，20-29 岁 +1.8/天，30-44 岁 +1.4/天，45 岁以上 +1.0/天。
- 梦遗：每晚 04:00 检查，概率随“距上次释放天数、睡眠债”增长，再乘以年龄系数（<18 岁 1.7、18-24 岁 1.5、25-34 岁 1.0、35-44 岁 0.55、45-54 岁 0.25、55 岁以上 0.10），最高 0.65；命中后欲望 -50，进入 2-6 小时恢复期。
- 年龄读不到时按 30 岁处理；年龄只影响这两条曲线，不拦任何功能。
- 晨勃：每天 07:30 检查，概率 0.22-0.36 再乘年龄系数（<20 岁 1.25、20-29 岁 1.15、30-39 岁 1.0、40-49 岁 0.85、50-59 岁 0.6、60 岁以上 0.35），只写事件。
- 白天反应：8:00-23:00 且欲望 >= 70 时，每天一次 12% 稳定哈希判定。
- 恢复期内欲望只按 0.25 倍积攒。

文本保持临床/叙事级别，不做解剖或体液细节。

修改状态需要管理员权限；查看不需要。

    身体              看状态
    身体 喂           吃一顿
    身体 零食         垫一垫
    身体 喝水         喝水
    身体 洗澡         清洁归零
    身体 刷牙         口腔归零
    身体 上厕所       膀胱归零
    身体 小睡         恢复精力
    身体 经期         查看周期
    身体 经期 开始    把今天记为第 1 天
    身体 经期 延后 2  周期延后 2 天
    身体 经期 提前 2  周期提前 2 天
    身体 经期 设置 2026-11-01

实际发送时带斜杠，例如 /身体 喂。别名 /生理、/body。

群聊里的状态卡只显示饥饿、口渴、精力；私聊才显示完整内部状态。成人指令在群聊会被拒绝。

## 插件页设置

WebUI -> 插件 -> 身体 · 生理需求 -> 设置。

可改：

- 启用身体系统
- 生理性别（auto/female/male/none）
- 年龄兜底（0 = 从人格读）
- 时区
- 睡眠时段
- 启用睡眠代谢
- 启用清洁与口腔
- 给模型身体工具
- 启用女性生理期
- 周期天数、经期天数、经期起点
- 启用成人私密生理
- 群聊细节（basic/full）
- 身体存在感（subtle/natural/strong）
- 附加提示
- 事件保留天数、最多事件数
- 调试日志


保存后立即生效，不需要重启；如果改的是时区，下一次请求会使用新时区。

## 数据与隐私

- 每个 Persona 一份 JSON：data/plugin_data/astrbot_plugin_body_needs/。
- 原子写入；损坏文件会改名为 .corrupt-时间戳。
- 群聊默认只给饥饿、口渴、精力；GROUP_DETAIL=full 才给非性相关的经期信息；欲望、梦遗、晨勃、白天反应永远不进群。
- 插件页是管理员页面，可看完整状态、改配置、按按钮照顾。
- 插件自身不发送消息，也不写 AstrBot 聊天历史。

## 已知边界

- 只在收到消息、工具调用、指令或页面请求时结算；没有后台定时器，不会在你没说话时自己喊饿。
- 不改变 persona_presence 的参与判断，也不影响 bili_whale 等独立 agent 的提示词。
- 性别/年龄是启发式；人格写得含糊时用配置指定。
- 食物、饮水、睡眠阶段、激素反馈都还是简化模型；详见 docs/SIMULATION.md。
- 周期症状是文学化描述，不是医学建议。
