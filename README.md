# 身体 · 生理需求

给 AstrBot 的 Persona 一副按真实时间运转的身体：胃内容、血糖、水合、膀胱、皮肤、口腔、睡眠债、女性周期（含青春期）、男性生理。它不是一个会主动说话的角色插件，而是给 Persona 提供“身体背景 + 记录工具”。

这是 astrbot_plugin_persona_presence 的伴侣插件，但它不依赖后者。完整公式、常量和已知简化见 [docs/SIMULATION.md](docs/SIMULATION.md)。

## 模型概要

- 胃内容、血糖、水合、尿量、皮肤脏度、口腔脏度、睡眠债是七个独立内部状态；饥饿、口渴、膀胱、清洁、口腔、精力是由它们推导出来的显示值，不是计数器。
- 时间按 15 分钟（间隔 ≤ 24 小时）或 1 小时（更久）分段积分，最多回溯 60 天，胃排空、血糖消耗、水合下降、膀胱充盈都是连续过程。
- 有昼夜节律（凌晨警觉度最低，上午和傍晚最高）和饭点食欲偏置。
- 女性有四阶段周期、三条简化激素曲线、周期内稳定的症状；青春期（年龄 < 18）另有初潮门槛、周期不规律、更强的痛经和经前反应。
- 男性有欲望、梦遗、晨勃、白天反应和 2-6 小时恢复期，其中欲望、梦遗、晨勃都随年龄变化。
- 年龄只喂生理曲线，不拦任何功能。成人内容的真正开关是：`ENABLE_INTIMATE` 开启 + 性别能被识别 + 只在私聊。

## 默认跟踪哪个人格

默认只跟踪“当前会话最终生效的人格”：一次 LLM 请求只推进这个人的状态，不会把人格库里所有人都结算一遍。

插件页没有会话上下文，所以默认显示 AstrBot 的默认人格，不会遍历所有人格。

设置页里有一个“固定人格”（`PERSONA_ID`）：

- 留空 = 跟随当前会话的人格。
- 选一个 = 所有会话都固定使用这个人的身体，聊天里切人格也不会换。

每个人格仍然有自己的 JSON 状态；只有被实际使用或被固定的人格才会被推进，其他旧文件不会被自动遍历。

## 它怎么运转

消息进入 -> 解析 Persona -> 读取该 Persona 的 JSON -> 按经过时间积分 -> 重算显示指标 -> 写回 JSON -> 生成提示块 -> 附加到本次 LLM 请求。

它不会发送消息，不写聊天历史，不替换 Persona 的系统提示。它只在下次开口时把身体状态作为背景交出去；模型可以选择提，也可以忽略。

## 内部状态和显示指标

| 内部状态 | 范围 | 驱动什么 |
| --- | --- | --- |
| 胃内容 | 0-100，越高越饱 | 饥饿 |
| 血糖 | 0-100，越低越饿 | 饥饿、精力 |
| 水合 | 0-100，越低越渴 | 口渴、尿量 |
| 尿量 | 0-100 | 膀胱 |
| 皮肤脏度 | 0-100 | 清洁 |
| 口腔脏度 | 0-100 | 口腔 |
| 睡眠债 | 0-24 小时 | 精力 |
| 欲望 | 0-100 | 亲密张力；`ENABLE_INTIMATE` 关闭或性别无法识别时恒为 0 |

显示指标：

    hunger = 0.55 * (100 - 胃内容) + 0.45 * (100 - 血糖) + (饭点偏置 - 1) * 20
    thirst = 100 - 水合
    bladder = 尿量
    cleanliness = 皮肤脏度
    fatigue = 0.55 * 睡眠债百分比 + 0.45 * (100 - 昼夜警觉度) + 惩罚
    惩罚 = max(0, 饥饿 - 70) * 0.20 + max(0, 口渴 - 70) * 0.15 + 经期 4

所以“刚吃完但血糖还低”会饿，“睡够但凌晨三点”会困，“喝了很多水”会很快想上厕所。

## 女性周期

周期是锚点 + 日历 + 简化激素曲线 + 稳定随机症状。

- 经期：第 1 到 `PERIOD_LENGTH` 天。
- 排卵期：周期中点 ±1 天。
- 黄体期：排卵之后到下次经期前。
- 经期后：其余。

激素（简化曲线，不是真实内分泌）：

- 雌激素：经期低，卵泡期上升，排卵期峰值约 90，黄体期下降。
- 孕激素：前半周期低，排卵后上升，黄体中后期峰值约 70，经前下降。
- LH：排卵期峰值 100，其他时间低。

症状包括经量（少/中/多三档）、小腹坠胀（0-3 级）、情绪、胃口；用“人格 id + 本次周期开始日”做种子，同一个周期内稳定，不会每轮刷新都变。经期开始/结束、进入排卵期、进入黄体期都会写事件并去重。

经期还会额外：疲劳惩罚 +4、皮肤脏度 +0.8/小时。

页面会显示三条激素小条；提示词只说身体感受，不直接说激素数值。

## 青春期

年龄 < 18 的角色按青春期处理。年龄从人格正文里读（“17岁”“年龄：17”这类写法），读不到才用配置 `AGE`，两者都没有就当成年、不启用青春期。

- 还没初潮：年龄 < 13 时阶段显示“未初潮”，不出血量、不写经期事件，提示词只说“还没来初潮，身体还在长”。
- 周期不规律：每个周期在配置长度上下浮动约 ±5 天（夹在 18-45 天），同一人格的序列稳定，所以“距下次”会比成年角色跳。
- 痛经更常见：经期小腹等级有 35% 概率再 +1（上限 3）。
- 经前反应更强：黄体期情绪额外 -1，经前 6 天的提示改成“情绪起伏比平时大”。
- 皮脂更多：皮肤脏度速率额外 +0.15/小时，洗澡会显得更必要。
- 提示词会在周期那一行末尾追加“（青春期，周期还不太规律）”。

## 男性

只在 `ENABLE_INTIMATE` 开启、性别 male 时运行；提示词和工具只在私聊出现。年龄不参与这个判断，只影响下面几条曲线。

- 欲望：20 岁以下 +2.0/天，20-29 岁 +1.8/天，30-44 岁 +1.4/天，45 岁以上 +1.0/天。
- 梦遗：每晚 04:00 检查，概率随“距上次释放天数、睡眠债”增长，再乘年龄系数（<18 岁 1.7、18-24 岁 1.5、25-34 岁 1.0、35-44 岁 0.55、45-54 岁 0.25、55 岁以上 0.10），最高 0.65；命中后欲望 -50，进入 2-6 小时恢复期。
- 晨勃：每天 07:30 检查，基础概率 0.22-0.36，再乘年龄系数（<20 岁 1.25、20-29 岁 1.15、30-39 岁 1.0、40-49 岁 0.85、50-59 岁 0.6、60 岁以上 0.35），只写事件。
- 白天反应：8:00-23:00 且欲望 >= 70 时，每天一次 12% 的稳定哈希判定，命中欲望 -8。
- 恢复期内欲望只按 0.25 倍积攒。
- 年龄读不到时按 30 岁处理。

文本保持临床/叙事级别，不做解剖或体液细节。

## 指令

修改状态需要管理员权限；查看不需要。

    身体              看状态
    身体 喂           吃一顿（别名：吃、吃饭、饿了）
    身体 零食         垫一垫
    身体 喝水         喝水（别名：喝、渴了）
    身体 洗澡         清洁归零（别名：洗、洗漱）
    身体 刷牙         口腔归零（别名：刷）
    身体 上厕所       膀胱归零（别名：厕所、尿）
    身体 小睡         恢复精力（别名：睡、困了、休息）
    身体 亲密         结算一次亲密（别名：舒缓，仅私聊）
    身体 经期         查看周期
    身体 经期 开始    把今天记为第 1 天
    身体 经期 延后 2  周期延后 2 天
    身体 经期 提前 2  周期提前 2 天
    身体 经期 设置 2026-11-01
    身体 重置

实际发送时带斜杠，例如 `/身体 喂`。指令名别名：`/生理`、`/body`。

群聊里的状态卡只显示饥饿、口渴、精力（经期且痛经明显时多一行）；私聊才显示完整内部状态。亲密在群聊会被拒绝。

## 插件页设置

WebUI -> 插件 -> 身体 · 生理需求 -> 设置。

可改：

- 启用身体系统
- 生理性别（auto/female/male/none）
- 年龄兜底（0 = 只从人格读；只影响生理曲线）
- 固定人格
- 时区
- 睡眠时段
- 启用睡眠代谢
- 启用清洁与口腔
- 给模型身体工具
- 启用女性生理期
- 周期天数（18-45）、经期天数（2-10）、经期起点
- 启用成人私密生理
- 群聊细节（basic/full）
- 身体存在感（subtle/natural/strong）
- 附加提示
- 事件保留天数（1-30）、最多事件数（5-100）
- 调试日志

保存后立即生效，不需要重启；如果改的是时区，下一次请求会使用新时区。

## 数据与隐私

- 每个 Persona 一份 JSON：`data/plugin_data/astrbot_plugin_body_needs/`。
- 原子写入；损坏文件会改名为 `.corrupt-时间戳` 并重建。
- 群聊默认只给饥饿、口渴、精力；`GROUP_DETAIL=full` 才给非性相关的经期信息和内部状态；欲望、梦遗、晨勃、白天反应永远不进群。
- 插件页是管理员页面，可看完整状态、改配置、按按钮照顾。
- 插件自身不发送消息，也不写 AstrBot 聊天历史。

## 已知边界

- 只在收到消息、工具调用、指令或页面请求时结算；没有后台定时器，不会在你没说话时自己喊饿。
- 不改变 persona_presence 的参与判断，也不影响 bili_whale 等独立 agent 的提示词。
- 性别/年龄是启发式；人格写得含糊时用配置指定。
- 食物、饮水、睡眠阶段、激素反馈都还是简化模型；详见 docs/SIMULATION.md。
- 周期症状是文学化描述，不是医学建议。
