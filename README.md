# 身体 · 生理需求

给 AstrBot 的 Persona 一副按真实时间运转的身体：胃内容、血糖、水合、膀胱、皮肤、口腔、睡眠债、女性周期（含青春期）、男性生理。它不是一个会主动说话的角色插件，而是给 Persona 提供“身体背景 + 记录工具”。

这是 astrbot_plugin_persona_presence 的伴侣插件，但它不依赖后者。完整公式、常量和已知简化见 [docs/SIMULATION.md](docs/SIMULATION.md)。

## 模型概要

- 状态里直接存正向指标：饱食度、水分、精力、清洁、口腔、膀胱压力、性欲（100 = 饱 / 润 / 有精神 / 干净 / 干净 / 很急 / 很强）；胃内容、血糖、尿量、皮肤和口腔脏度、肠道内容、睡眠债是驱动它们的隐藏储备。
- 每个角色有一套固定的体质（睡眠需求、代谢、胃容量、肠道通过速度、释放习惯），由人格 id 决定。
- 时间按 15 分钟（间隔 ≤ 24 小时）或 1 小时（更久）分段积分，最多回溯 60 天，胃排空、血糖消耗、水合下降、膀胱充盈都是连续过程。
- 有昼夜节律（凌晨警觉度最低，上午和傍晚最高）和饭点食欲偏置。
- 女性有四阶段周期、下丘脑-垂体-卵巢闭环（FSH/雌二醇/LH/孕激素/卵泡互相反馈）、周期内稳定的症状和连续的基础体温；青春期（年龄 < 18）另有初潮门槛、周期不规律、更强的痛经和经前反应。
- 宫颈黏液拆成量、性状、颜色、拉丝长度、宫颈位置/软硬/开合；外阴再拆成大阴唇、小阴唇、阴蒂、前庭、会阴，并单列阴道（张力/温度/开合）；器官负荷给膀胱、肾脏、肝脏、子宫、卵巢，另有直肠、尿道、肛门的当前状态，而不只是激素数值。
- 体味分成全身汗味、头皮、口气、脚、经期血腥味、哺乳奶味和亲密之后的事后余味，洗澡/刷牙分别压掉对应来源。
- 男性有性欲、梦遗、晨勃、白天反应和 2-6 小时恢复期，其中性欲、梦遗、晨勃都随年龄变化。
- 年龄只喂生理曲线，不参与任何开关；性内容只由 `ENABLE_INTIMATE` 开启 + 性别能被识别 + 只在私聊决定。

## 默认跟踪哪个人格

默认只跟踪“当前会话最终生效的人格”：一次 LLM 请求只推进这个人的状态，不会把人格库里所有人都结算一遍。

插件页没有会话上下文，所以默认显示 AstrBot 的默认人格，不会遍历所有人格。

设置页里有一个“固定人格”（`PERSONA_ID`）：

- 留空 = 跟随当前会话的人格。
- 选一个 = 所有会话都固定使用这个人的身体，聊天里切人格也不会换。

每个人格仍然有自己的 JSON 状态；只有被实际使用或被固定的人格才会被推进，其他旧文件不会被自动遍历。

## 它怎么运转

消息进入 -> 解析 Persona -> 读取该 Persona 的 JSON -> 按经过时间积分 -> 重算显示指标 -> 写回 JSON -> 生成提示块 -> 附加到本次 LLM 请求。

它不会发送消息，不写聊天历史，不替换 Persona 的系统提示。它只在下次开口时把身体状态作为背景交出去；模型可以选择提，也可以忽略。

## 内部状态和显示指标

| 字段 | 范围 | 含义 |
| --- | --- | --- |
| `satiety` 饱食度 | 0-100 | 越高越饱 |
| `hydration` 水分 | 0-100 | 越高越润 |
| `energy` 精力 | 0-100 | 越高越有精神 |
| `cleanliness` 清洁 | 0-100 | 越高越干净 |
| `oral_health` 口腔 | 0-100 | 越高越清爽 |
| `bladder` 膀胱压力 | 0-100 | 越高越急 |
| `libido` 性欲 | 0-100 | 越高越强；`ENABLE_INTIMATE` 关闭或性别无法识别时恒为 0 |
| `stomach` / `glucose` | 隐藏 | 计算饱食度 |
| `urine` | 隐藏 | 计算膀胱压力 |
| `skin` / `oral` | 隐藏 | 脏度，计算清洁 / 口腔 |
| `sleep_debt` | 隐藏 | 计算精力 |
| `gut` / `bowel` | 隐藏 | 排便压力 |
| `kidney_load` / `liver_load` | 隐藏 | 肾脏、肝脏的慢负荷代理 |
| `uterine_congestion` | 隐藏 | 子宫充血/收缩的慢变量 |
| `scalp_scent` / `breath_scent` / `intimate_scent` | 隐藏 | 头皮、口气和角色事后气味 |
| 体质 | 每人固定 | 睡眠需求、代谢率、胃容量、肠道通过速度、释放习惯 |

推导关系：

    satiety = 0.55 * 胃内容 + 0.45 * 血糖 - (饭点偏置 - 1) * 20 - 情绪食欲项
    hydration = 水合（直接存）
    energy = 100 - [0.55 * 睡眠债百分比 + 0.45 * (100 - 昼夜警觉度) + 惩罚]
    cleanliness = 100 - 皮肤脏度
    oral_health = 100 - 口腔脏度
    bladder = 尿量
    bowel = max(0, 肠道内容 - 25) * 1.5
    惩罚 = max(0, 40 - 饱食度) * 0.20 + max(0, 40 - 水分) * 0.25
         + max(0, 排便 - 70) * 0.10 + 经期 4

所以“刚吃完但血糖还低”会饱食度偏低，“睡够但凌晨三点”会精力偏低，“喝了很多水”会很快想上厕所。

页面、状态卡、提示词读的都是这些存储值，显示层不再做 100 − x。旧版本的状态文件在加载时自动迁移（`hunger` → `100 - hunger` 等），迁移测试锁死了这一步。

## 行为结算

这些是她自己做的事（自动作息，或剧情里由 `body_action` 记录），会改内部状态、显示指标自动重算：

| 行为 | 效果 |
| --- | --- |
| 吃饭 | 饱食度↑，肠道 +14，睡眠债 -0.3h（胃 +55、血糖 +28） |
| 零食 | 饱食度小幅↑（胃 +22、血糖 +12） |
| 喝水 | 水分↑，膀胱压力↑ |
| 洗澡 | 清洁 ≈98（皮肤脏度归 2），睡眠债 -0.3h |
| 刷牙 | 口腔 ≈98（口腔脏度归 2） |
| 上厕所 | 小便压力 = 0；排便压力 ≥20 时肠道 -85，同时记录排便 |
| 小睡 | 精力↑，睡眠债 -2.5h |
| 做爱（仅私聊） | 性欲 = 0，皮肤 +4，睡眠债 -0.4h，男性进入 2-6 小时恢复期 |
| 自己解决性欲（仅私聊） | 性欲 -30，男性进入 1-3 小时恢复期 |
| 产检（孕期） | 记录本次产检周数，写一条事件 |
| 哺乳（哺乳期） | 乳汁 -65 |

## 自主照料

她的身体由她自己维持，不受聊天指令控制，也不需要“喂饭”。按日常节奏自动发生：

- 三餐在 7-10、12-15、18-21 三个窗口里，每人每天按 persona_id + 日期抽一个偏好时刻（小时+分钟）；到点后胃内容 ≤90、距上次进食 >1 小时就吃（早饭 30、午饭/晚饭 32），分别写“自己吃了早饭/午饭/晚饭”；
- 喝水不再定点：7-23 点之间水分 ≤72、距上次喝水 >1 小时就喝 10；
- 厕所：7 点起床后固定一次，其余 7-23 点尿量 ≥30 时去；排便压力到 75 也会去；
- 洗澡在 7-10 或 20-23 的偏好小时、皮肤脏度 ≥60 时；刷牙在 7-10 或 21-24、口腔脏度 ≥55 时；
- 卫生用品剩 2 片以内会自己补货；涨奶到 85 会自己喂/挤。

这些行为会写 `self_care` 事件（三餐按槽位各一条，其他按天/次去重）；喝水、厕所和洗漱同时写入独立的 `care` 时间线。页面用两条视图展示：**日常**列出三餐时间和喝水/厕所/洗澡/刷牙次数，**作息**按最近 24 小时画成 5×24 的小时网格（类似 GitHub 贡献图），并标出“现在”。聊天里不会出现“喂她”的指令，模型只会从事件里知道她刚才做了什么；如果剧情里她真的吃了什么，由模型调用 `body_action` 记录。

## 自慰

对角色，自慰不分性别、也不限时段：性欲 ≥12 时按小时判定，概率随习惯和当前性欲增长；睡眠中概率降低但不为零。命中后性欲 -30，女性再按年龄曲线微调性欲涨速（20 岁出头最高，之后缓降），男性进入 1-3 小时恢复期。自慰/做爱会留下一点事后气味，洗澡会明显压掉。

频率优先由**模型对人格的判断**决定：插件把人格正文发一份给当前对话模型，要求它只输出 `{"libido": 0-100}`，再把分数映射到 0.3-4.8 的习惯系数（50 分 ≈ 1.2，也就是普通人）。判断结果按“人格 id + 正文哈希”缓存到 `data/plugin_data/astrbot_plugin_body_needs/libido_scores.json`，正文不变就只调用一次；改人格或删缓存会重新判断。

没有可用 provider、模型拒绝或输出无法解析时，回退到按 persona_id 抽出的固定习惯（0.3-4.8 对数分布），所以不会因为一次判断失败就没有频率。实测分布：中位数约 1 次/天，10% 低于 0.4 次/天，10% 高于 1.7 次/天，最高约 2.3 次/天（模型判断偏低/偏高时会相应移动）。事件每天只记第一条，只在私聊进入提示词，群聊永远看不到。

## 和人格情绪联动

每次推进后，插件会往数据目录写一份 `vitals.json`：`valence`（-1 到 1）、`arousal`、`distress`、`tension`、`pain`、`energy`、`dirt`、`libido`，以及 `labels` 和一行 `line`（例如“饿着，耐心比平时薄”）。

persona_presence 的情绪资料片会读这份文件：按 `tension` 往“恼/不安”、按负 `valence` 往“低落”、按 `distress` 往下压“开心”、按 `dirt` 往“嫌”上加一点底色，并在情绪块前加一行 `[身体]`。所以饿、困、疼、憋着会真实地改变她此刻的情绪，而不是只在提示词里报数值。

反向也会走同一条路：情绪插件把人格级心情写到 `mood.json`，身体在推进时读取——低落和生气会压低食欲与性欲，恐惧和生气会轻微拉长卵泡期。两端都是文件契约，任一插件缺失时静默跳过。情绪资料片的 `emotion_body_link` 可以单独关掉。

## 女性周期

周期是锚点 + 日历 + 闭环激素模型 + 稳定随机症状。

- 经期：第 1 到 `PERIOD_LENGTH` 天。
- 排卵期：排卵日 ±1 天。排卵日不再是周期中点，而是**下次经期往前推 14 天**。
- 黄体期：排卵之后到下次经期前（固定 14 天）。
- 经期后：其余。

所以排卵推迟 = 周期变长 = 下次经期推后。卵泡期会被睡眠债拉长（最多 +35%），这个长度决定排卵日晚多少、整个周期长多少。

周期按天连续走，不按日历月对齐（28 天本来就和月份对不上）。长时间不互动也一样：最多回放一年，超过 60 天用 2 小时步长，所以离开三个月回来时，相位仍然对应当天，而不是停在离开那天。

具体机制：五个变量一起积分——FSH 养大卵泡，卵泡分泌雌二醇，雌二醇反过来压低 FSH、并把 LH 推成一个陡峰；LH 峰冲过阈值才排卵，黄体分泌孕激素、满 14 天溶解，下一次经期开始。卵泡生长速率按配置的周期长度反解，所以 28 天人格仍然落在第 14 天前后；睡眠债会拉长卵泡期，实测 28 天周期在睡眠债 18 小时会推后到 33 天。

激素是随时间积分出来的状态变量（不是按天查表）：

- 雌激素：经期低，卵泡期上升，排卵期峰值约 90，黄体期下降。
- 孕激素：前半周期低，排卵后上升，黄体中后期峰值约 70，经前下降。
- LH：排卵前陡升到 70-100 的峰，排卵后迅速回落。
- FSH：经期前后最高，随雌二醇上升被压下去，黄体溶解后再放开。

基础体温和分泌物直接由激素推导：孕激素把基础体温抬高约 0.2-0.4℃，排卵后维持偏高；宫颈黏液由雌二醇主导，越接近排卵越稀薄拉丝，黄体期重新变稠。

症状包括经量（少/中/多三档）、小腹坠胀（0-3 级）、情绪、胃口；用“人格 id + 本次周期开始日”做种子，同一个周期内稳定，不会每轮刷新都变。经期开始/结束、进入排卵期、进入黄体期都会写事件并去重。

经期还会额外：疲劳惩罚 +4、皮肤脏度 +0.8/小时。

页面会显示 E2/P4/LH/FSH 四条激素条和相对数值（0-100）；提示词只说身体感受，不直接说激素数值。

### 经前症状

黄体期最后一周会按周期稳定地给出：乳房胀（0-2）、头痛（0-2）、腰酸（0-2）、小腹不适（0-3）、胃口（-1~1），以及由雌二醇和孕激素连续推导出的情绪（-3~3）。这些只出现在提示词和页面上，不影响别的指标。

### 分泌物与宫颈

旧的 0-3 档仍然是内部兼容字段，但页面和私聊细节已经拆成多层：

- **量**：0-100，提示词写成很少/少量/中等/偏多/很多。
- **性状**：干爽、黏稠、乳白糊状、水样、蛋清样、混着经血、带一点血丝。
- **颜色**：透明、乳白、白色、淡黄、淡粉、褐色、红色；排卵期点滴出血会变成淡粉/带血丝。
- **拉丝**：0-9 cm，接近排卵时最长；黄体期重新变短。
- **宫颈**：偏低/中位/偏高，偏硬/中等/偏软，闭合/微微张开；排卵前偏高、偏软、微张，黄体期和经期偏低、偏硬、闭合。
- **外阴**：大阴唇（饱满/微微分开/张开）、小阴唇（贴合/微露/外翻）、阴蒂（藏着/微露/充血挺起）、前庭（干燥/湿润/泛着水光/泛红）、会阴（正常/有点发红/发胀），由唤起度分档；
- **阴道**：张力（紧致/柔软/松软/薄而干）、温度（温热/发烫）、开合（闭合/微张/张开）；
- **其他**：盆腔坠胀（0-100），乳房胀满（0-100）。

这些字段都由同一组雌二醇/孕激素驱动，和基础体温、旧 0-3 档不会互相打架。唤起度 = max(湿润度, 0.9×性欲) + 排卵 12 + 经期 6 + 孕期 8，外阴和阴道按它分档。经期显示为“经血为主 + 经量 + 颜色”，孕期显示为乳白/水样分泌物。私聊提示给两行：一是“分泌物：…；宫颈…”，二是“外阴：大阴唇…、小阴唇…、阴蒂…、前庭…、会阴…；阴道：…”；页面周期卡显示量/性状/颜色、拉丝、宫颈、外阴五层、阴道三相、盆腔和乳房。

### 器官负荷

页面新增“器官负荷”卡片，私聊提示给一行“器官：…”。这些是虚构的负荷代理，不是医学检查：

- **膀胱**：沿用原有膀胱压力，0-100，越高越急；尿色偏深时会提示喝水。
- **肾脏**：由缺水、钠、咖啡因、尿色和孕期/生病缓慢积分，时间常数约 8 小时；水分不足、盐和咖啡因多时负担上升。
- **肝脏**：由长期饮食质量、消化不适、咖啡因、盐、生病和疼痛缓慢积分，时间常数约 10 小时；油糖多、胃里胀时负担上升。
- **子宫**：由周期阶段、经量、痛经和孕期缓慢积分，时间常数约 6 小时；经期充血最高，卵泡期最低。
- **卵巢**：按周期显示“一侧卵泡在长/一侧正在排卵/排卵后形成黄体/无排卵/绝经后安静”，不单独存负荷值。
- **直肠**：按肠道内容算“空的/有点内容/有便意/憋得慌”，排便后清零；它和“排便压力”是同一件事的两个视角。
- **尿道**：由尿色、缺水、咖啡因和经期缓慢积分，时间常数约 8 小时；排尿后会短暂上升，洗澡降一点。
- **肛门**：每次排便后刺激上升（便干、缺水更明显），时间常数约 10 小时；洗澡会明显压下去。

器官负荷和激素条是两套视角：激素说“现在处在周期的哪一段”，器官负荷说“这段身体累不累”。肾脏/肝脏超过 75 会轻微拉低精力，子宫充血高时会多一点点坠痛；幅度刻意做得很小，不会压过饥饿、睡眠和痛经。

### 体味

体味不再是一个总分，而是按来源分开：

- **全身**：皮脂、出汗、清洁度、经期和排卵期共同决定；
- **头皮**：皮脂、出汗和距上次洗澡的时间，发根和枕头先有油味；
- **口气**：口腔脏度、口干、咖啡因、消化不适和生病；吃辣/油后会先上来一点；
- **脚**：出汗、久坐、闷热，洗澡会明显下降；
- **经期**：按经量和时间累积的血腥味；
- **哺乳**：哺乳期乳汁较多时胸前有奶味；
- **事后**：女性是淡淡的腥甜味，男性是淡淡的腥味，混着汗味。刚结束最明显（事中也已经有味），之后一天半内都会提一句，洗澡压掉；梦遗也留味。

洗澡分别压掉全身、头皮、脚、经期和事后气味，刷牙压掉口气。页面“体味”卡片分来源显示；私聊只在某项真的明显时给一句，不会把所有来源都念一遍——事后是例外：只要 36 小时内有过释放，就一定会提，因为刚做完的那一刻本来就有味道，不该等数值攒够。

### 无排卵周期

按年龄给概率（青春期 55%、16-19 岁 25%、20-44 岁 8%、围绝经期 35%）。这类周期没有排卵期，孕激素和 LH 都不升高，出血是雌激素撤退性的；提示词会写“本周期无排卵”。

### 生育窗口

排卵日前 5 天到排卵日当天是易孕期（精子能活约 5 天，卵子只有 1 天）。无排卵周期没有窗口。

窗口是**跟着排卵日走的，不是跟着经期走的**：

| 周期长度 | 排卵日 | 易孕日 |
|---|---|---|
| 28 天 | 第 14 天 | 第 9-15 天 |
| 24 天 | 第 10 天 | 第 5-11 天 |
| 21 天 | 第 7 天 | 第 2-8 天（涵盖经期末尾） |

所以“经期刚结束能不能怀孕”取决于排卵早不早：周期越短，经期尾段本身就可能落在易孕期内。28 天周期的第 6-8 天确实不在窗口里，这是正常的。

私聊里易孕期会多一行“身体：这几天更容易受孕”；`/身体` 状态卡和插件页的生理期卡也会标出“易孕：是/否”。

### 怀孕与避孕

女性人格在易孕期亲密时按概率受孕：

| 避孕方式 | 受孕概率 |
|---|---|
| 不避孕 | 18% |
| 安全套 | 0.36% |
| 避孕药 | 0.18% |

受孕后周期停止，提示词按孕周推进（6-12 周会写恶心犯困，28 周后写行动不便），单胎 280 天、双胎 266 天、三胎 252 天后写一条出生事件并重置周期。

受孕时会抽一次胎数：单胎约 98.7%，双胎 1.2%，三胎 0.08%。孕早期每周有递减的流产风险（6 周前 2.5%/周、6-9 周 2.0%、10-12 周 1.0%、13-19 周 0.4%），睡眠债最高会把风险放大到 1.5 倍；流产后写一条事件并恢复周期。

12/20/28/36 周会自动写一条产检事件（12 周起提示单胎/双胎/三胎），也可以 `/身体 产检` 手动记录一次。

产后自动进入哺乳期：乳汁每小时 +4.5，涨到 85 以上她会自己喂/挤，也可以 `/身体 哺乳` 手动处理；一年后自然停止。

受孕判定只看三件事：性别是女性、当前没在孕期、当下处于易孕期。**不看年龄**，年龄只参与生理曲线。可以在设置里关掉整个怀孕机制（`ENABLE_PREGNANCY`）。

### 做爱与受精页

私聊的 `intimacy` 会记录做爱次数、内射次数和上次时间；`body_action` 多了一个可选 `ejaculated`（默认 true，明确没有被内射时传 false），只有内射才会参与受孕判定。插件页的生理期卡下方有“受精”示意：卵子/精子、等待受精/已受精、易孕、单次概率、湿润度和次数统计。

性欲高时身体会积累湿润度（0-100，受性欲、易孕和排卵影响）；私聊提示词在 20/45/75 三档会写“下面有点湿，身体发热 / 内裤有点潮 / 内裤湿了一小片”。

自慰后 body 只发布 `away_until` 和 `desire`，不自己抢先静默。接 persona_presence 时，由它的决策 AI 读 `vitals.json`，按人格决定“这条先不回、去解决一下”；如果决定去，它写 `body_request.json`，body 在下一个私聊事件里执行 release 并设置 away。`ENABLE_AWAY` 默认关闭，只作为没有 persona_presence 时的独立静默开关。自慰仍然由后台 `_maybe_release` 按性欲和习惯自主判定，不靠模型调用工具。

### 多囊

人格正文里出现“多囊 / PCOS”时按多囊处理：排卵率降到 15%（也就是 85% 的周期无排卵）、周期长度漂移扩大到 ±12 天、LH 常年偏高。这类人格的周期会明显比普通人更乱更久。

### 卫生用品

经期按当天的经量扣片数：**量多每 2 小时换一次、量中等 4 小时、量少 6 小时**（按每天 16 个清醒小时折算，也就是 8 / 4 / 3 片）。所以头两天用量最大，五天经期大约 20 片，而不是固定 12 片。

用完了会写一条事件，提示词显示“卫生用品：已经用完了”；`/身体 补货`（别名：卫生巾、卫生用品）或工具的 `supplies` 补 20 片。页面周期卡片会显示剩余片数。

## 年龄、种族与周期

年龄只喂生理曲线，性功能不按年龄关闭。女性的周期按“人类等效年龄”判定：

- 初潮：每个人格按**正态分布**抽一个固定值（均值 12.5 岁、标准差 1.1，夹在 9-16 岁）。低于它就是“未初潮”，所以 12 岁的角色有的已经来潮、有的还没有。

  实测分布（4000 个人格抽样）：

  | 初潮年龄 | 占比 |
  | --- | --- |
  | 9-10 岁 | 1.2% |
  | 10-11 岁 | 6.6% |
  | 11-12 岁 | 24.6% |
  | 12-13 岁 | 35.8% |
  | 13-14 岁 | 23.9% |
  | 14 岁以上 | 8.0% |

- 绝经：同样按正态分布抽（均值 51 岁、标准差 4，夹在 40-61 岁），不再是一刀切的 50 岁。

  | 绝经年龄 | 占比 |
  | --- | --- |
  | 40-45 岁 | 7.3% |
  | 45-48 岁 | 15.8% |
  | 48-51 岁 | 27.7% |
  | 51-54 岁 | 27.4% |
  | 54 岁以上 | 21.7% |

- 围绝经期：绝经前 4 年进入过渡期，周期漂移扩大到 ±9 天、无排卵概率升到 35%，提示词会出现“围绝经期，周期开始不太规律，偶尔潮热”。
- 长寿种族：人格正文里写了精灵、恶魔、吸血鬼、矮人、龙族、天使、神族，就按对应寿命折算（精灵 1200 年、恶魔 3000 年、吸血鬼 2000 年、龙族 5000 年、天使 1000 年、神族 8000 年、矮人 250 年）。精灵 300 岁 ≈ 人类 20 岁，走正常周期；精灵 600 岁 ≈ 人类 40 岁，接近绝经。
- 也可以用 `LIFESPAN` 直接指定寿命，覆盖自动识别。
- 年龄 <= 100 一律按字面值处理，所以“精灵少女，17 岁”仍然是 17 岁，不会被折成婴儿。
- 青春期（人类等效年龄 < 18）：周期在配置值上下浮动约 ±5 天、痛经和经前反应更强、皮脂分泌更多，提示词会追加“（青春期，周期还不太规律）”。同时会算一个 0-1 的“内分泌成熟度”（发育前/发育早期/青春期/成年/绝经后），用于分泌物量、乳房胀满和体味曲线。

## 男性

只在 `ENABLE_INTIMATE` 开启、性别 male时运行；提示词和工具只在私聊出现。年龄只影响下面几条曲线。

- 性欲：基础 +80/天（18-19 岁）、+70/天（20-29 岁）、+50/天（30-44 岁）、+32/天（45 岁以上），同时按 24 小时半衰期自然回落。释放频率优先用模型对人格的判断（0-100 → 0.3-4.8 习惯系数），判断失败时回退到 persona_id 抽出的固定值；中位数约 1 次/天，高习惯可到 2 次以上。
- 梦遗：每晚 04:00 检查，概率随“距上次释放天数、睡眠债”增长，再乘年龄系数（18-24 岁 1.5、25-34 岁 1.0、35-44 岁 0.55、45-54 岁 0.25、55 岁以上 0.10），最高 0.65；命中后性欲 -50，进入 2-6 小时恢复期。
- 晨勃：每天 07:30 检查，基础概率 0.22-0.36，再乘年龄系数（18-19 岁 1.25、20-29 岁 1.15、30-39 岁 1.0、40-49 岁 0.85、50-59 岁 0.6、60 岁以上 0.35），只写事件。
- 白天反应：8:00-23:00 且性欲 >= 70 时，每天一次 12% 的稳定哈希判定，命中性欲 -8。
- 恢复期内性欲只按 0.25 倍积攒。
- 性欲不是“攒满才释放”的计数器：每 24 小时自然回落一半，所以长期不释放也不会永远顶在 100。
- 年龄读不到时按 30 岁处理。

文本保持临床/叙事级别，不写露骨过程细节；分泌物和器官状态用中性描述。

## 睡眠与作息

她不是按一张固定时间表生活的人，睡眠由两个过程叠出来：

- **睡眠债**：醒着时每小时涨一点，睡着时每小时还一点。
- **昼夜警觉度**：凌晨最低，上午和傍晚最高。

到了习惯就寝时间（SLEEP_WINDOW 的起点 ± 人格时型 ± 每天的小抖动），即使还不困也会上床；上床后还要躺一会儿才睡得着——越不困躺得越久（10-50 分钟）。特别困时会提前躺下；手上正忙着（看B站、听歌、发说说）会把上床往后推，最多压到锚点后三小时，除非睡眠债已经高到 17 小时，那时候困意会赢。

睡着以后由睡够没有决定几点醒：睡够需求（7-8.5 小时，欠得多时会多睡一点）就自然醒，睡得晚起得也晚。约一半的下午还会午睡 20-60 分钟。

**作息会漂，但会自己踩住。** 没有工作、没有必须早起的事，她的相位每天会往后挪几分钟到十几分钟，昨晚实际比计划睡得晚还会再往后带一点，所以会从 00:30 慢慢变成 01:30、02:30。但她会注意到这一点：约七成的晚上会想“今天早点睡”，把计划提前（最多一小时）——通常还是会拖到老时间，可这个念头会把相位往回拉。越晚漂得越慢，长期稳定在 01:30-03:00 睡、10:00-12:00 醒，偶尔有凌晨四点的晚夜，但不会一路滑到早上。早上 5-9 点醒、睡债高时还会再往回拉一些。想固定作息就把 SLEEP_WINDOW 当作锚点，相位仍会在它附近漂几小时。


睡眠也带着她的日常走：起床后刷牙、上厕所、吃早饭，午饭后移，晚饭在睡前 3 小时，洗澡按人格分成“起床后洗”或“睡前洗”。睡着时所有会话都不回复（指令除外）；躺在床上还没睡着时不算，可以迷迷糊糊回一句。醒来后第一句话会带上“睡着时没看到的消息”。

同一个约定也发布给别的插件：data/plugin_data/astrbot_plugin_body_needs/sleep.json（asleep、in_bed、wake_at、bedtime、nap_at、busy_until），同进程还可以直接调用 sleep_snapshot()。字段和读取规则见 docs/SLEEP_LINK.md。

## 已知边界
